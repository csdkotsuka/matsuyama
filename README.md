## 🌟 主な特徴と収録コンテンツ

### 1. 🏛️ 歴史と物語 (History & Legends)
- **道後温泉本館**: 日本最古・3,000年の歴史。約5年半の保存修理を経て2024年7月に全館営業再開！
- **夏目漱石と『坊っちゃん』**: 漱石の松山での英語教師体験から生まれた痛快青春小説の軌跡。
- **松山城**: 日本に12基しか残っていない貴重な現存天守。標高132mの勝山山頂にそびえる名城。
- **『坂の上の雲』の舞台**: 正岡子規と秋山好古・真之兄弟。明治の黎明期を駆け抜けた若き群像。

### 2. ✒️ 俳句とことば文化 (Literature & Haiku)
- **正岡子規と近代俳句の夜明け**: 「写生」を提唱し、五・七・五を近代文学へ昇華させた父。
- **街中90箇所以上の「俳句ポスト」**: 誰でもいつでも一句詠んで投句できる街の文化。
- **俳句甲子園**: 全国高校生が松山に集い、自作の句と論理的ディベートで競う熱戦。

### 3. 🎨 芸術と現代アート (Art & Aesthetics)
- **蜷川実花 × 道後温泉**: 極彩色の花々と光の写真アートが歴史ある温泉街を包み込む。
- **道後オンセナート**: 草間彌生、荒木経惟ら世界的アーティストが集う「街歩き型オープンミュージアム」。
- **安藤忠雄建築**: 松山城の緑に溶け込む「坂の上の雲ミュージアム」の空中階段構造。
- **坊っちゃん劇場 & 音楽文化**: 四国・愛媛の歴史を題材にしたオリジナルミュージカル常設劇場。

### 4. 🍊 農産物・柑橘王国 (Citrus Kingdom)
- **日本屈指の柑橘王国**: 「3つの太陽（直射日光・海の反射光・石垣の熱）」が育む極上の甘み。
- **奇跡の高級柑橘**: ゼリー食感の「紅まどんな」、甘みが弾ける「甘平」、柑橘の大トロ「せとか」、「伊予柑」。
- **都市伝説の現実化「蛇口からみかんジュース」**: 松山空港や道後温泉、ロープウェイ街での体験スポット。

### 5. 🐟 水産物・極上の美味 (Fisheries & Gastronomy)
- **2大「鯛めし」大対決**: 
  - 【宇和島鯛めし】新鮮な鯛刺身を特製タレと生卵で豪快にかき込む南予風
  - 【松山鯛めし】素焼きの真鯛を一尾丸ごと昆布出汁でふっくら炊き込む中予風
- **八幡浜・南予のソウルフード「じゃこ天」**: 小魚を骨ごとすり身にして揚げたカルシウム満点の味。
- **宇和海・瀬戸内の恵み**: 「全身大トロ」の幻の高級魚スマ（伊予の媛貴海）、太刀魚巻焼き、宇和島真珠。

### 6. ⚾ 意外なトリビア・歴史秘話 (Trivia & Curiosities)
- **正岡子規と野球（ベースボール）の深すぎる絆**:
  - 自身の幼名「升（のぼる）」にちなみ、雅号として「野球（野・球 / の・ぼーる）」を使用
  - 「打者」「走者」「直球」「四球」「飛球」などの訳語を考案・普及
  - 日本で初めて野球を短歌や俳句に詠み込み、2002年に野球殿堂（特別表彰）入り！
- **「中村愛媛県知事は歌舞伎役者！？」の真相大解剖**:
  - 噂の正体は、歌舞伎の名門「六代目 中村時蔵（萬屋）」と名前・字面が酷似していることによる有名な混同
  - さらに愛媛県には国の重要文化財である現役芝居小屋「内子座（うちこざ）」があり、定期的に歌舞伎が公演される文化的背景も重なった
  - 実際の中村時広知事は、慶應大・三菱商事・松山市長（3期11年）を経て知事を務める実務派リーダー！
- **『坊っちゃん』の毒舌と松山市民の愛**: ボロクソに書かれながらも街を挙げて大歓迎した温かいおもてなし精神。

## 🐙 GitHubへのアップロード（公開）手順

ローカルのリポジトリはすでに初期化・初回コミット済みです。以下の手順でご自身のGitHubアカウントにアップロードできます。

### ステップ 1: GitHubで新規リポジトリを作成
1. ブラウザで [GitHub](https://github.com) にログイン
2. 右上の「+」メニューから **「New repository」** をクリック
3. リポジトリ名を入力（例: `matsuyama-discovery`）
4. Public（公開）を選択し、**「Initialize this repository with:」のチェックボックス（READMEなど）はすべて外した状態**で「Create repository」をクリック

### ステップ 2: ローカルからGitHubへプッシュ
ターミナルで以下のコマンドを実行します（`<ユーザー名>` と `<リポジトリ名>` はご自身のアカウントのものに置き換えてください）：

```bash
# リモートリポジトリ（GitHub）の登録
git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git

# メインブランチをGitHubへプッシュ
git branch -M main
git push -u origin main
```

### ステップ 3: GitHub Pagesで全世界へ無料公開（おすすめ！）
プッシュ完了後、GitHub上で無料のWebサイトとして世界中に即時公開できます：
1. GitHubのリポジトリページを開き、上部タブの **「Settings」** をクリック
2. 左メニューの **「Pages」** をクリック
3. **Build and deployment** の Source で **「Deploy from a branch」** を選択
4. Branch を **`main`** / `/ (root)` に設定し、**「Save」** をクリック
5. 数十秒〜数分で、世界中からアクセス可能な公開URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）が発行されます！
