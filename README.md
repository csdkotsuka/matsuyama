## 🌟 主な特徴と収録コンテンツ（全8大カテゴリ）

### 1. ☁️ 『坂の上の雲』大特集 (Clouds Above the Hill) ★特設
- **秋山好古・真之兄弟の不屈の生涯**:
  - 兄・好古: 「日本騎兵の父」として世界最強コサック騎兵を撃破。陸軍大将退役後は元帥を辞退し、故郷・松山の中学校長（現・松山北高校）として教育に尽力。
  - 弟・真之: 日本海海戦の名参謀としてバルチック艦隊撃滅作戦を立案。「本日天気晴朗ナレドモ浪高シ」の不朽の名文。
- **坂の上の雲ミュージアム（安藤忠雄建築）**:
  - 松山城の緑に溶け込む三角形の現代建築。支柱のない「空中階段」が未来へ坂を登り続ける物語の志を体現。
- **萬翠荘（ばんすいそう）**:
  - 大正11年建築、愛媛県最古のフランス・ルネサンス風洋館（国指定重要文化財）。旧松山藩主子孫・久松定謨伯爵の別邸。

### 2. 🏛️ 歴史と物語 (History & Legends)
- **道後温泉本館**: 日本最古・3,000年の歴史。約5年半の保存修理を経て2024年7月に全館営業完全再開！
- **夏目漱石と『坊っちゃん』**: 漱石の松山での英語教師体験から生まれた痛快青春小説の軌跡。
- **松山城**: 日本に12基しか残っていない貴重な現存天守。標高132mの勝山山頂にそびえる名城。

### 3. ✒️ 俳句とことば文化 (Literature & Haiku)
- **正岡子規と近代俳句の夜明け**: 「写生」を提唱し、五・七・五を近代文学へ昇華させた父。
- **街中90箇所以上の「俳句ポスト」**: 誰でもいつでも一句詠んで投句できる街の日常。
- **俳句甲子園**: 全国高校生が松山に集い、自作の句と論理的ディベートで競う熱戦。

### 4. 🎨 芸術と現代アート・伝統工芸 (Art & Crafts)
- **蜷川実花 × 道後温泉**: 極彩色の花々と光の写真アートが歴史ある温泉街を包み込むコラボレーション。
- **国指定伝統的工芸品「砥部焼（とべやき）」**: 240年の歴史を持つ素朴で頑丈な白磁と藍色（呉須）の唐草文様。
- **世界的ブランド「今治タオル」**: 霊峰・石鎚山の清らかな軟水が育む「5秒ルール」の奇跡の吸水性と肌触り。

### 5. 🍊 農産物・柑橘王国 (Citrus Kingdom)
- **日本一の柑橘王国・愛媛**: 「3つの太陽（直射・海面反射・石垣の輻射熱）」が生む極上の甘み。
- **奇跡の高級柑橘カルテット**: ゼリー食感の「紅まどんな」、甘み弾ける「甘平」、柑橘の大トロ「せとか」、「伊予柑」。
- **都市伝説の現実化「蛇口からみかんジュース」**: 松山空港や道後温泉、ロープウェイ街の体験スポット案内。

### 6. 🐟 水産物・極上の美味 (Fisheries & Gastronomy)
- **2大「鯛めし」大対決**: 
  - 【宇和島鯛めし】新鮮な鯛刺身を特製タレと生卵で豪快にかき込む南予風
  - 【松山鯛めし】素焼きの真鯛を一尾丸ごと昆布出汁でふっくら炊き込む中予風
- **八幡浜・南予のソウルフード「じゃこ天」**: 小魚を骨ごとすり身にして揚げたカルシウム満点の味。
- **松山市民のソウルフード「鍋焼きうどん」＆「一六タルト」**: アルミの小鍋で供される甘い出汁のうどんと、江戸時代南蛮伝来の柚子香るロールタルト。

### 7. 🧭 絶景と名所巡り (Scenic Wonders)
- **瀬戸内しまなみ海道**: CNN選出「世界7大サイクリングコース」。島々と海を渡るサイクリストの聖地（中村時広知事が国際化を牽引）。
- **夕暮れの奇跡「JR下灘駅」＆観光列車「伊予灘ものがたり」**: 海に最も近い駅として世界を魅了する茜色の絶景。
- **四国遍路と「お接待」の心**: 1200年続く四国八十八ヶ所霊場（松山市内にも石手寺・浄瑠璃寺など名刹）と、旅人を無償でもてなす慈悲の精神。

### 8. ⚾ 意外なトリビア・歴史秘話 (Trivia & Curiosities)
- **正岡子規と野球（ベースボール）の深すぎる絆**:
  - 幼名「升（のぼる）」にちなみ、雅号として「野球（野・球 / の・ぼーる）」を使用
  - 「打者」「走者」「直球」「四球」「飛球」などの日本語訳語を考案・普及
  - 日本で初めて野球を短歌や俳句に詠み、2002年に野球殿堂（特別表彰）入り！
- **「中村愛媛県知事は歌舞伎役者！？」の真相大解剖**:
  - 噂の正体は、歌舞伎界の名門・萬屋の大幹部「六代目 中村時蔵（萬屋）」氏と知事の「中村時広」氏の名前・字面が酷似していることから生まれた有名な混同
  - さらに愛媛県には国の重要文化財である大正時代の本格木造芝居小屋「内子座（うちこざ）」があり、定期的に歌舞伎が公演される文化的背景も重なった
  - 実際の中村時広知事は、慶應大・三菱商事・松山市長（3期11年）を経て知事を務める生粋の実務派リーダー！
- **『坊っちゃん』の毒舌と松山市民の愛**: 小説内で散々けなされながらも、街の象徴として愛し続ける松山人の温かいユーモア精神。

## 🐙 GitHubへのアップロード（公開）手順

ローカルのリポジトリはすでに初期化・コミット済みです。以下の手順でご自身のGitHubアカウントにアップロードできます。

### ステップ 1: GitHubで新規リポジトリを作成
1. ブラウザで [GitHub](https://github.com) にログイン
2. 右上の「+」メニューから **「New repository」** をクリック
3. リポジトリ名を入力（例: `matsuyama-discovery`）
4. Public（公開）を選択し、**「Initialize this repository with:」のチェックボックス（READMEなど）はすべて外した状態**で「Create repository」をクリック

### ステップ 2: ローカルからGitHubへプッシュ
ターミナルで以下のコマンドを実行します（`<ユーザー名>` と `<リポジトリ名>` はご自身のアカウントのものに置き換えてください）：

```bash
# リモートリポジトリ（GitHub）の登録
git remote add origin https://github.com/<ユーザー名>/<リポジトリ名>.git

# メインブランチをGitHubへプッシュ
git branch -M main
git push -u origin main
```

### ステップ 3: GitHub Pagesで全世界へ無料公開
プッシュ完了後、GitHub上で無料のWebサイトとして世界中に即時公開できます：
1. GitHubのリポジトリページを開き、上部タブの **「Settings」** をクリック
2. 左メニューの **「Pages」** をクリック
3. **Build and deployment** の Source で **「Deploy from a branch」** を選択
4. Branch を **`main`** / `/ (root)` に設定し、**「Save」** をクリック
5. 数十秒〜数分で、世界中からアクセス可能な公開URL（`https://<ユーザー名>.github.io/<リポジトリ名>/`）が発行されます！
