> **3,000年の古湯から、坂の上の雲、極彩色のアート、霊峰と海の絶景へ**

## 🌟 主な特徴と収録コンテンツ（全8大カテゴリ）

### 1. ☁️ 『坂の上の雲』大特集 (Clouds Above the Hill) ★特設
- **秋山好古・真之兄弟の不屈の生涯**:
  - 兄・好古: 「日本騎兵の父」としてコサック騎兵を撃破。陸軍大将退役後は元帥推薦を辞退し、故郷・松山の中学校長（現・松山北高校）として教育に尽力。
  - 弟・真之: 日本海海戦の名参謀としてバルチック艦隊撃滅作戦を立案。「本日天気晴朗ナレドモ浪高シ」の不朽の名文。
- **坂の上の雲ミュージアム（安藤忠雄建築）**:
  - 松山城の緑に溶け込む三角形の現代建築。支柱のない「空中階段」が未来へ坂を登り続ける物語の志を体現。
- **萬翠荘（ばんすいそう・国指定重要文化財）**:
  - 大正11年建築、愛媛県最古のフランス・ルネサンス風洋館。旧松山藩主子孫・久松定謨伯爵が築いた気品あふれる宮殿。

### 2. 🏛️ 歴史と名城 (History & Fortress)
- **道後温泉本館**: 日本最古・3,000年の歴史。約5年半の保存修理を経て2024年7月に全館営業完全再開！
- **松山城 ＆ 二之丸史跡庭園**:
  - 「日本の城ランキング」第2位に輝く美しい現存天守（日本三大連立式平山城）。
  - 発掘された藩主邸の間取りを池や流水園・柑橘で立体再現した世界的にも稀有な史跡庭園。日露戦争のロシア将校と日本人看護婦の愛の金貨が出土した「恋人の聖地」。
- **夏目漱石と名作『坊っちゃん』**: 漱石の松山での英語教師体験から生まれた痛快青春小説の軌跡。

### 3. ✒️ 俳句とことば文化 (Literature & Haiku)
- **正岡子規と近代俳句の夜明け**: 「写生」を提唱し、五・七・五を近代文学へ昇華させた父。
- **街中90箇所以上の「俳句ポスト」**: 誰でもいつでも一句詠んで投句できる街の日常。
- **俳句甲子園**: 全国高校生が松山に集い、自作の句と論理的ディベートで競う熱戦。

### 4. 🎨 極彩色アート＆工芸 (Art & Master Crafts)
- **蜷川実花 × 道後温泉**: 極彩色の花々と光の写真アートが歴史ある温泉街を包み込むコラボレーション（本館巨大ラッピング、飛鳥乃湯泉中庭、アートルーム）。
- **砥部焼（とべやき）の進化**: 240年の歴史を持つ素朴で頑丈な白磁呉須の「民藝の実用美」から、パリやNYのミシュラン星付きレストランで絶賛される薄手白磁・青白磁の最高級アートピースへ。
- **世界的ブランド「今治タオル」**: 霊峰・石鎚山の清らかな軟水が育む「5秒ルール」の奇跡の吸水性と肌触り。

### 5. 🍊 農産物・柑橘王国 (Citrus Kingdom)
- **日本一の柑橘王国・愛媛**: 「3つの太陽（直射・海面反射・石垣の輻射熱）」が生む極上の甘み。
- **奇跡の高級柑橘カルテット**: ゼリー食感の「紅まどんな」、甘み弾ける「甘平」、柑橘の大トロ「せとか」、「伊予柑」。
- **都市伝説の現実化「蛇口からみかんジュース」**: 松山空港や道後温泉、ロープウェイ街の体験スポット案内。

### 6. 🐟 水産・郷土の美味 (Fisheries & Local Gastronomy)
- **鯛めしの真実と歴史：【釜飯・炊き込み】vs【生卵刺身ぶっかけ】**:
  - 【松山・北条鯛めし】1700年前、神功皇后が鹿島（北条）で戦勝祈願した際に漁師が献上した土釜炊き込みご飯が起源！香ばしいおこげと鯛の旨味。
  - 【宇和島鯛めし】伊予水軍が船上で火を使わずに生卵とタレでかき込んだ豪快めし。
  - 【松山での売れ筋】観光客には生卵ぶっかけが人気だが、地元では伝統の鯛釜飯も絶大な支持！名店では両方の「食べ比べセット」が大ヒット！
- **産学官共同研究の結晶「みかん鯛」**:
  - 愛媛県・愛媛大学・養殖業者が共同開発！みかん果皮オイルを食べて育ち、魚臭さが消えてほんのり柑橘香が漂う革新的なブランド魚。
- **県民が一番愛する真のソウルフード菓子「母恵夢（ポエム）」**:
  - 「タルトや坊っちゃん団子よりポエムが好き！」白餡にバターと卵黄を練り込んだ黄金の餡とバニラの香り。県民のDNAに刻まれた味。

### 7. ⛰️ 四国山地＆海の絶景 (Peaks & Island Vistas)
- **西日本最高峰・霊峰「石鎚山（いしづちさん）」**: 標高1,982m、日本七霊山。鎖場のスリルと天狗岳の鋭峰、山岳信仰の聖地。
- **瓶ヶ森（かめがもり）と「UFOライン」**: 標高1,897m。車の全国CMで話題沸騰となった天空の稜線ロード。氷見二千石原の笹原の絶景。
- **亀老山（きろうさん）展望公園**: しまなみ海道・大島にある隈研吾氏設計の「見えない展望台」。トリップアドバイザー日本の展望スポット第2位！来島海峡大橋の夕日・夜景。
- **四国遍路と「お接待」**: 1200年の巡礼道。松山・石手寺の仁王門は国宝！文化庁「日本遺産第1号」に認定され、現在ユネスコ世界文化遺産登録を目指す心の文化。

### 8. ⚾ 意外なトリビア・歴史秘話 (Trivia & Curiosities)
- **正岡子規と野球（ベースボール）の深すぎる絆**:
  - 幼名「升（のぼる）」にちなみ、雅号として「野球（野・球 / の・ぼーる）」を使用
  - 「打者」「走者」「直球」「四球」「飛球」などの日本語訳語を考案・普及
  - 日本で初めて野球を短歌や俳句に詠み、2002年に野球殿堂（特別表彰）入り！
- **「中村愛媛県知事は歌舞伎役者！？」の真相大解剖**:
  - 歌舞伎界の名門・萬屋の大幹部「六代目 中村時蔵」氏と知事の「中村時広」氏の名前・字面が酷似していることによる有名な混同
  - さらに愛媛県には大正時代の本格木造芝居小屋「内子座（うちこざ）」があり、定期的に歌舞伎が公演される文化的背景も重なった
  - 実際の中村時広知事は、慶應大・三菱商事・松山市長（3期11年）を経て知事を務める実務派リーダー！
- **現代の話題「リベラルアーツ大学（リベ大）」と愛媛の熱気**:
  - 自立と学びを応援するコミュニティの広がりと地域の起業家・学習熱。

## 🚀 ローカルでの動作確認方法

特別なビルド環境（Node.jsなど）は不要です。標準的なWeb標準（HTML5 / Vanilla JS / Tailwind CSS CDN）で構築されています。

### 方法1: ブラウザで直接開く
`index.html` をダブルクリックして任意のブラウザで開くだけで即座に動作します。

### 方法2: ローカルHTTPサーバーで動かす
```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```
